Upload one HTML file. Share one sandboxed preview.

Share HTML hosts a self-contained .html or .htm file behind a sandboxed preview. No signup is required; anonymous uploads expire after 365 days.

Choose how the link opens

  • Public unlisted — anyone with the link can open the share metadata and preview. Share URLs are never added to the sitemap.
  • Private link — the returned share URL carries its access key in a client-side #key= fragment. Unlocking sets short-lived, path-scoped HttpOnly metadata and preview grants; treat the whole URL as a secret.

Create a share with the API

# Public unlisted (the default)
curl -X POST https://sharehtml.zhenjia.dev/api/shares \
  -F "file=@page.html" -F "title=My page"

# Access-key-protected private link
curl -X POST https://sharehtml.zhenjia.dev/api/shares \
  -F "file=@page.html" -F "visibility=private_link"
# The private response includes accessKey and a share_url with #key=...
