产品决策PRODUCT DECISIONS

先补上证据链，再判断要加码哪种分发。Close the evidence gaps before doubling down on distribution.

  1. 让创建入口可验证Make creation paths verifiable

    以服务端受控枚举记录入口、方法和成功结果，避免让调用方自由文本承担归因。Record source, method, and outcome with server-controlled enums instead of free-text attribution from callers.

  2. 分别测量 SEO 与 GEOMeasure SEO and GEO separately

    搜索曝光/点击、AI 搜索请求、浏览器来源、创建成功是不同事件；把可连接的匿名事件分层保存。Search impressions/clicks, AI-search requests, browser referrals, and successful creation are different events. Store linkable, privacy-conscious events separately.

  3. 给 WebMCP 和 remote MCP 加结果遥测Instrument WebMCP and remote MCP outcomes

    记录注册/支持情况、实际方法调用、结果与失败，区分浏览器 WebMCP 的 API 请求和 remote MCP handler。Record support/registration, method calls, results, and failures. Distinguish browser WebMCP API requests from remote MCP handlers.

  4. 维持单页交付质量Keep single-page delivery reliable

    公开 HTML 显示多样任务需求；继续确保链接打开快、内容隔离、移动端可用。分类覆盖不足前，不把单一类别当作市场定论。Public HTML shows varied tasks. Keep links fast, isolated, and usable on mobile. Do not treat one category as the market verdict while classification coverage remains incomplete.

静态分类与人工抽查Static classification and manual review

状态标记为 active 的 2,453 个唯一公开文件全部通过 HTTP 成功读取。解析标题、meta、H1–H3、可见文本、表单/画布等标记及少量脚本库名称；没有运行上传脚本或加载外部资源。类别依简明关键词规则单标签匹配：标题、描述和标题层级权重较高，正文每个词的贡献有限；低分与并列项目保留未分类。“规则匹配强度”不是经校准的语义置信度。All 2,453 unique public artifacts marked active were successfully retrieved over HTTP. Parsing covered title, metadata, H1–H3, visible text, form/canvas tags, and a small set of script-library names. Uploaded scripts and remote resources were not run or loaded. A simple single-label keyword rule weights title, description, and headings more heavily; body-word contributions are bounded. Low scores and unresolved ties stay unclassified. “Rule match strength” is not calibrated semantic confidence.

研究者抽查 90 个未分类样本，按大标题簇与语言分层选取，不是随机抽样，不能外推占比。未分类常见原因包括品牌标题、语言词汇缺口、静态页面文字很少或内容需在浏览器执行后才出现；它不等于无用途。HTML lang 是声明，不是经验证的语言，也不代表用户所在地。A reviewer inspected 90 unclassified samples selected from large title clusters and language strata. Unclassified does not mean purposeless. HTML lang is a declaration, not verified language or user location.

重复、内容访问与隐私Repeats, content requests, and privacy

快照中的内容访问计数是每条链接的累计请求数，包含分享页内嵌加载与直接打开 HTML；该计数无法区分两种打开方式。另有带时间戳的应用事件汇总，可按日查看请求、按分享记录计算首次请求延迟及固定 7 日观察窗。事件可能重复或由自动化触发，不能识别独立读者或用户留存；当前状态与累计计数也不是时间顺序漏斗。Snapshot content-request counts are cumulative per link and include both embedded loads and direct HTML opens; the counters cannot distinguish the two. A separate timestamped application-event aggregate provides daily requests, first-request delay by share, and fixed seven-day follow-up windows. Events may repeat or be automated and do not identify unique readers or user retention. Current status and cumulative counters are not a chronological funnel.

7/1 至截点的应用日志共有 14,969 次 viewed 事件；快照中 7–9 月创建链接的累计计数合计 14,939 次，差额 30 次来自 7 月前创建的链接。因此，事件时间序列与按创建月分组的快照累计数是不同总体。Application logs contain 14,969 viewed events from July 1 to cutoff. Cumulative counters on links created from July through September sum to 14,939; the difference of 30 requests belongs to links created before July. The event time series and snapshot counters grouped by creation month therefore cover different populations.

精确 hash 只识别字节完全一致内容。标题骨架统计经过日期/版本号正规化，并排除空指纹；相似标题不能证明同一个文件、模板或用户。Exact hashes detect byte-identical content only. Title-pattern counts normalize dates and version numbers and exclude empty fingerprints. Similar titles do not prove the same file, template, or user.
